# CLAUDE.md

This repo stores skills, subagents and agentic workflows. It has no application code. It is also a Claude Code plugin marketplace (`stevnsborg`) that publishes everything as one plugin, `awf`.

## Rules

- **Never hand-edit `skills/third-party/`.** It is generated by `scripts/sync_skills.py` from `skills/manifest.json`. To change a third-party skill, fork it into `skills/custom/` under a new name.
- **Never hand-edit `.claude/skills/`, `.claude/agents/` or `.claude-plugin/marketplace.json`.** `scripts/link.py` generates them.
- Custom skills go in `skills/custom/<name>/SKILL.md`. Agents go in `agents/<name>.md`. Workflows go in `workflows/<name>/`. Start from `templates/`.
- Everything in `skills/custom/` and `agents/` ships in the plugin. Keep drafts and docs out of those folders.
- A skill's frontmatter `name` must match its folder name.
- Before vendoring a new source, check its license. Only vendor permissively licensed skills (MIT, Apache-2.0, ...). For anything else, add it to the manifest with `"vendor": false`.

## After any change

```bash
python3 scripts/link.py && python3 scripts/validate.py
claude plugin validate .   # if the claude CLI is available
```

CI (`.github/workflows/validate.yml`) runs the Python checks and fails if the generated files are stale.
