# CLAUDE.md

This repo stores skills, subagents and agentic workflows. It has no application code.

## Rules

- **Never hand-edit `skills/third-party/`.** It is generated by `scripts/sync_skills.py` from `skills/manifest.json`. To change a third-party skill, fork it into `skills/custom/` under a new name.
- **Never hand-edit `.claude/skills/` or `.claude/agents/`.** They are symlinks generated by `scripts/link.py`.
- Custom skills go in `skills/custom/<name>/SKILL.md`. Custom agents go in `agents/custom/<name>.md`. Workflows go in `workflows/<name>/README.md`. Copy the matching `_template` to start.
- A skill's frontmatter `name` must match its folder name.
- Before vendoring a new source, check its license. Only vendor permissively licensed skills (MIT, Apache-2.0, ...). For anything else, add it to the manifest with `"vendor": false`.

## After any change

```bash
python3 scripts/link.py && python3 scripts/validate.py
```

CI (`.github/workflows/validate.yml`) runs the same checks.
